# Contributing how-to

One document per question. Check here before starting work instead of guessing,
and update the relevant document — and this index — when practices change.

`make` lists every target; `make check` runs every quality gate. These documents
name targets rather than restating the commands behind them.

| [working-on-specs.md](working-on-specs.md) | How do I add or change a spec, and when is a spec required? |
